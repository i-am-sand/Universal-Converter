# Converter

## `main.cpp`

Точка входа в программу.

### Что делает `main.cpp`

- создаёт объект `QApplication`;
- создаёт главное окно `MainWindow`;
- показывает окно пользователю;
- запускает основной цикл приложения.

---

## `mainwindow.h`

Описан класс `MainWindow`.

Главное окно отвечает за:

- ввод исходного числа;
- ввод исходной системы счисления;
- ввод целевой системы счисления;
- запуск конвертации;
- загрузку данных из файла;
- сохранение результата в файл;
- вывод ошибок пользователю.

### Что хранит `MainWindow`

- `ui` — указатель на интерфейс окна;
- `converter_` — объект класса `Converter`, который выполняет перевод числа.

### Основные слоты

- `on_convertButton_clicked()` — вызывается при нажатии кнопки **«Конвертировать»**;
- `on_loadButton_clicked()` — вызывается при нажатии кнопки загрузки файла;
- `on_saveButton_clicked()` — вызывается при нажатии кнопки сохранения результата.

## `mainwindow.cpp`

Код методов главного окна.

### Основные части

#### Конструктор

- создаёт интерфейс окна;
- подключает `ui` к `MainWindow`.

#### Деструктор

- удаляет `ui`.

#### `on_convertButton_clicked`

Метод вызывается при нажатии кнопки **«Конвертировать»**.

Что делает метод:

- очищает поле результата;
- очищает старую ошибку;
- сбрасывает старую подсветку полей;
- проверяет, что поле с числом не пустое;
- проверяет, что поле исходной системы счисления не пустое;
- проверяет, что поле целевой системы счисления не пустое;
- проверяет, что основания систем счисления являются числами;

- считывает число из поля ввода;

- получает результат;

- считывает число;

- записывает результат в выбранный файл.

# Логика конвертации

## `Converter.h`

Описан класс `Converter`.

Класс `Converter` отвечает за общий процесс перевода числа.

### Основной метод

- `convert(...)` — переводит число из одной системы счисления в другую.

### Что получает `convert`

- `input` — строка с исходным числом;
- `from_base` — основание исходной системы счисления;
- `to_base` — основание целевой системы счисления.

### Что возвращает `convert`

Метод возвращает строку с результатом перевода.

---

## `Converter.cpp`

Код класса `Converter`.

### Основная логика

- создаётся объект `Parser`;
- создаётся объект `Formatter`;
- `Parser` разбирает введённое число;
- число переводится во внутренний вид `BigFraction`;
- `Formatter` переводит `BigFraction` в строку в нужной системе счисления;
- готовая строка возвращается в `MainWindow`.

`Converter` сам не разбирает цифры и не форматирует результат.  
Он только соединяет `Parser` и `Formatter`.

---

# Разбор входного числа

## `Parser.h`

Описаны структура `ParsedNumber` и класс `Parser`.

`ParsedNumber` хранит разобранное число.

### Что хранит `ParsedNumber`

- `integer_digits` — цифры целой части;
- `fractional_digits` — цифры дробной части;
- `period_digits` — цифры периода;
- `has_point` — есть ли точка в числе;
- `has_period` — есть ли период в числе.

### Основные методы `Parser`

- `parse(...)` — разбирает строку и переводит её в `BigFraction`;
- `ReadDigit(...)` — считывает одну цифру из строки;
- `split(...)` — разбивает число на целую часть, дробную часть и период;
- `to_BigInteger(...)` — переводит набор цифр в `BigInteger`.

---

## `Parser.cpp`

Код методов класса `Parser`.

### `posMessage`

Создаёт текст с номером позиции ошибки.

### `ReadDigit`

Считывает одну цифру.

Поддерживает:

- обычные цифры `0-9`;
- буквы `A-Z`;
- буквы `a-z`;
- большие цифры в квадратных скобках, например `[123]`.

Также метод проверяет, что цифра меньше основания системы счисления.  
Если цифра недопустима, выбрасывается ошибка.

### `split`

Разбирает строку с числом.

Что делает метод:

- отделяет целую часть;
- отделяет дробную часть;
- отделяет период;
- проверяет правильность точки;
- проверяет правильность круглых скобок;
- проверяет отсутствие пробелов внутри числа;
- проверяет, что целая часть существует;
- проверяет, что период не пустой.

### `to_BigInteger`

Берёт список цифр и переводит их в большое целое число.

Работает по принципу:

```cpp
result = result * base + digit;
```

### `powBigInteger`

Возводит `BigInteger` в степень.  
Используется для вычисления знаменателя дроби.

### `parse`

Главный метод парсера.

Что делает метод:

- проверяет основание исходной системы;
- вызывает `split`;
- получает целую часть, дробную часть и период;
- строит числитель и знаменатель;
- возвращает число в виде `BigFraction`.

---

# Формирование результата

## `Formatter.h`

Описан класс `Formatter`.

`Formatter` отвечает за вывод результата в нужной системе счисления.

### Основные методы

- `format(...)` — переводит `BigFraction` в строку;
- `digit_to_string(...)` — переводит одну цифру в строку;
- `integer_to_base(...)` — переводит целую часть в нужную систему счисления.

Также в этом файле задана константа:

- `MAX_OUTPUT_LENGTH` — максимальная длина результата.

---

## `Formatter.cpp`

Код методов класса `Formatter`.

### `digit_to_string`

Переводит одну цифру в строку.

Правила:

- если цифра меньше `10`, она выводится как обычная цифра;
- если цифра от `10` до `35`, она выводится как буква `A-Z`;
- если цифра больше `35`, она выводится в квадратных скобках.

Пример:

```text
[123]
```

### `integer_to_base`

Переводит целую часть числа в нужную систему счисления.

Что делает метод:

- делит число на основание системы;
- собирает остатки;
- переворачивает порядок цифр;
- получает строку с целой частью результата.

### `format`

Главный метод форматирования.

Что делает метод:

- проверяет основание целевой системы счисления;
- получает целую часть числа;
- получает остаток дробной части;
- переводит целую часть;
- если дробной части нет, сразу возвращает результат;
- если дробная часть есть, переводит её отдельно;
- запоминает остатки, чтобы найти период;
- если остаток повторился, ставит круглые скобки;
- если результат слишком длинный, обрезает его и выводит предупреждение.

# Большие числа

## `BigInteger.h`

Описан класс `BigInteger`.

`BigInteger` нужен для работы с большими целыми числами.  
Обычные типы `int` и `long long` не подходят, потому что число может быть очень большим.

### Что хранит `BigInteger`

- `digits_` — блоки большого числа;
- `Mbase_` — основание одного блока;
- `Mbase_digits` — количество десятичных цифр в одном блоке.

### Основные методы и операторы

- `BigInteger()` — создаёт ноль;
- `BigInteger(uint64_t value)` — создаёт число из обычного целого;
- `BigInteger(const std::string& decimal)` — создаёт число из строки;
- `toString()` — переводит `BigInteger` в строку;
- `isZero()` — проверяет, является ли число нулём;
- `trim()` — удаляет лишние нули;
- `operator+` — сложение;
- `operator-` — вычитание;
- `operator*` — умножение;
- `operator/` — деление;
- `operator%` — остаток от деления;
- `gcd(...)` — нахождение НОД;
- операторы сравнения: `<`, `>`, `<=`, `>=`, `==`, `!=`.

---

## `BigInteger.cpp`

Код методов класса `BigInteger`.

### Конструктор по `uint64_t`

Разбивает обычное число на блоки.

### Конструктор по строке

Что делает:

- проверяет, что строка состоит из цифр;
- разбивает строку на блоки по `9` цифр;
- сохраняет блоки в `digits_`.

### `trim`

Удаляет лишние нулевые блоки в конце числа.

### `toString`

Собирает число обратно в строку.

Что делает:

- первый блок выводит как есть;
- остальные блоки дополняет нулями до `9` цифр.

### `isZero`

Проверяет, что число равно нулю.

### `operator+`

Складывает два больших числа по блокам и учитывает перенос.

### `operator-`

Вычитает одно большое число из другого и учитывает заём из следующего блока.  
Отрицательные числа не поддерживаются.

### `operator*`

Умножает большие числа.  
Работает похоже на умножение в столбик.

### `operator/`

Делит большие числа.  
Использует подбор цифры частного бинарным поиском.

### `operator%`

Находит остаток от деления.

### `gcd`

Находит наибольший общий делитель.  
Используется алгоритм Евклида.

### Операторы сравнения

Сначала сравнивают количество блоков.  
Потом сравнивают блоки от старшего к младшему.

# Дроби

## `BigFraction.h`

Описан класс `BigFraction`.

`BigFraction` нужен для точной работы с дробями.  
Он хранит дробь не через `double`, а как числитель и знаменатель.

### Что хранит `BigFraction`

- `num_` — числитель;
- `den_` — знаменатель.

Оба поля имеют тип `BigInteger`.

### Основные методы и операторы

- `BigFraction()` — создаёт дробь `0/1`;
- `BigFraction(BigInteger num, BigInteger den)` — создаёт дробь по числителю и знаменателю;
- `BigFraction(BigInteger num)` — создаёт целое число как дробь;
- `num()` — возвращает числитель;
- `den()` — возвращает знаменатель;
- `integerPart()` — возвращает целую часть;
- `remainder()` — возвращает остаток от деления числителя на знаменатель;
- `operator+` — сложение дробей;
- `operator-` — вычитание дробей;
- `operator*` — умножение дробей;
- `operator/` — деление дробей;
- операторы сравнения: `<`, `>`, `<=`, `>=`, `==`, `!=`.

---

## `BigFraction.cpp`

Код методов класса `BigFraction`.

### `cut`

Сокращает дробь.

Что делает:

- находит НОД числителя и знаменателя;
- делит числитель и знаменатель на НОД.

### Конструктор `BigFraction(BigInteger num, BigInteger den)`

Что делает:

- проверяет, что знаменатель не равен нулю;
- сокращает дробь;
- сохраняет числитель и знаменатель.

### `operator+=`

Складывает дроби.

Что делает:

- приводит дроби к общему знаменателю;
- складывает числители;
- сокращает результат.

### `operator-=`

Вычитает дроби.

Что делает:

- проверяет, что результат не будет отрицательным;
- приводит дроби к общему знаменателю;
- вычитает числители;
- сокращает результат.

### `operator*=`

Умножает дроби.

Что делает:

- умножает числители;
- умножает знаменатели;
- сокращает результат.

### `operator/=`

Делит дроби.

Что делает:

- переворачивает вторую дробь;
- умножает на неё первую дробь;
- проверяет деление на ноль;
- сокращает результат.

### Операторы сравнения

Сравнивают дроби через перемножение крест-накрест.

# Логика работы программы

1. Пользователь вводит число.
2. Пользователь вводит исходную систему счисления.
3. Пользователь вводит целевую систему счисления.
4. Нажимает кнопку **«Конвертировать»**.
5. `MainWindow` считывает данные из интерфейса.
6. `MainWindow` проверяет пустые поля и основания систем счисления.
7. `MainWindow` вызывает `Converter`.
8. `Converter` создаёт `Parser` и `Formatter`.
9. `Parser` разбирает строку.
10. `Parser` переводит число в `BigFraction`.
11. `Formatter` переводит `BigFraction` в нужную систему счисления.
12. `MainWindow` выводит результат пользователю.

---

# Поддерживаемый формат чисел

- `0-9` — обычные цифры;
- `A-Z` — цифры от `10` до `35`;
- `a-z` — цифры от `10` до `35`;
- `[123]` — цифра больше `35`;
- `.` — разделитель дробной части;
- `(...)` — период дробной части.

## Примеры допустимых чисел

```text
1011
1A
10.25
0.(3)
10.1(01)
1[123]4
```

---

# Ограничения

- основание системы счисления должно быть от `2` до `500`;
- отрицательные числа не поддерживаются;
- в числе не должно быть пробелов;
- период можно записывать только после точки;
- квадратные скобки используются только для одной цифры больше `35`;
- слишком длинный результат обрезается.

---

# Работа с файлами

Кнопка загрузки открывает текстовый файл.

Из файла считываются три строки:

```text
исходная система счисления
целевая система счисления
число
```

Пример файла:

```text
10
2
15
```

Кнопка сохранения сохраняет результат в выбранный текстовый файл.

---

# Ошибки

Программа выводит ошибку, если:

- поле числа пустое;
- поле исходной системы счисления пустое;
- поле целевой системы счисления пустое;
- основание меньше `2`;
- основание больше `500`;
- основание не является числом;
- цифра не подходит для выбранной системы счисления;
- внутри числа есть пробел;
- неправильно записана дробная часть;
- неправильно записан период;
- не закрыта квадратная скобка;
- не закрыта круглая скобка.

При ошибке:

- в поле вывода появляется `:(`;
- рядом выводится текст ошибки;
- проблемные поля подсвечиваются.

# Особенности реализации

- интерфейс сделан через Qt;
- логика интерфейса отделена от логики перевода;
- `Parser` отвечает только за разбор числа;
- `Formatter` отвечает только за вывод числа;
- `Converter` соединяет `Parser` и `Formatter`;
- `BigInteger` нужен для больших целых чисел;
- `BigFraction` нужен для точной работы с дробями;
- дроби не считаются через `double`, поэтому нет ошибок округления;
- период дроби находится по повторению остатков.
